# Website Admin: Quick Guide for Staff

**Sign in:** go to `yourwebsite.org/admin` → type your email and password → **Sign In**.
Forgot it? Tap **Forgot your password?** (or ask an Admin to reset it for you).

## Add an event
1. **Events** → **＋ Add an Event**
2. Type the name, pick the date, type the time (like `9:00 AM`), where, and details. A photo is optional.
3. Tap **Publish to Website** (shows right away) or **Save as Draft** (only you see it).
4. Want to check first? **Save Draft & Preview** shows it on the real page, only to you.

## Change or remove something
- **Events / Announcements** → find it → **Edit** → **Save Changes**.
- **Take Down** hides it from the website but keeps it as a draft. **Delete** removes it for good.
- Past events disappear from the website by themselves.

## Announcements
**Announcements** → **＋ Add an Announcement** → headline, topic, message, optional photo and link → **Publish**.

## Photos
**Photos** → **Upload Photos**. Big phone photos are shrunk automatically. Use them from any event or announcement with **Choose or Upload Photo**.

## Top banner (Admins only)
**Top Banner** → change the message or switch it off → **Save Banner**.

## People (Admins only)
**People** → **＋ Add a Person** → name, email, Editor or Admin → give them the temporary password shown (they choose their own on first sign-in). Use **Reset Password**, **Turn Off Access** or **Remove** as needed.

## Good habits
- Always **Sign Out** on shared computers (it also signs out after 60 idle minutes).
- Choose a long password (10+ characters) that you don't use elsewhere.
- If something looks wrong, don't worry: nothing is public until you tap **Publish**.
